
# ATM Interface - Java Project

## Project Description
A console-based ATM Interface developed using Java.
It simulates basic ATM banking operations.

## Features
- PIN authentication
- Check account balance
- Withdraw money
- Deposit money
- View transaction history
- View account details
- Exit the application

## Technologies Used
- Java
- Object-Oriented Programming (OOP)
- ArrayList
- Java Date and Time API

## How to Run

Compile all Java files:

    javac *.java

Run the application:

    java Main

## Note
This is an educational console-based project.
It does not connect to a real bank or ATM network.
